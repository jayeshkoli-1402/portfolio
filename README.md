# Jayesh Koli — Portfolio

A dark, terminal-themed ML engineer portfolio.

## Deploying to GitHub Pages

1. Create a new GitHub repo (e.g. `jayeshkoli-1402.github.io` for the root domain, or any name for a project page)
2. Upload all files maintaining this structure:
   ```
   index.html
   assets/
     energy.jpeg
     Code_Clash.pdf
     Web_of_innovation.pdf
     Python.pdf
     Numpy_Scipy__Matplotli_and_Pandas.pdf
   ```
3. Go to repo **Settings → Pages → Source: Deploy from branch → main → / (root)**
4. Your site will be live at `https://jayeshkoli-1402.github.io/`

## Add your profile photo

Place your profile photo at `assets/profile.jpg` — the portfolio uses the terminal widget instead of a photo, so this is optional.

## Update social links

In `index.html`, LinkedIn and GitHub links are already set. Update the nav's `href="mailto:"` if email changes.
